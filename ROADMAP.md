# Mona's Bookmark Roadmap

A focused plan for making bookmark capture, organization, and recovery simple.

| Area | Item | Type | Priority |
| --- | --- | --- | --- |
| Discovery | Search and filter bookmarks | 🚀 | High |
| Editing | Edit a bookmark | 🚀 | High |
| Organization | Add tags or folders | 🚀 | Medium |
| Portability | Import and export bookmarks | 🚀 | Medium |
| Data integrity | Prevent duplicate slugs | 🐞 | High |
| Validation | Reject empty URLs | 🐞 | High |
| Persistence | Warn before localStorage loss | 🐞 | Medium |

## 🚀 Planned features

- 🔎 Search and filter bookmarks — priority: high
- ✏️ Edit a bookmark — priority: high
- 🏷️ Add tags or folders — priority: medium
- 📦 Import and export bookmarks — priority: medium

## 🐞 Known bugs & risks

- 🐞 Duplicate slugs on re-add — priority: high
- ⚠️ Empty-URL validation gaps — priority: high
- 💾 Losing bookmarks when localStorage is cleared — priority: medium
